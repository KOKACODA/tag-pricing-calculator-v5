## 功能一览

### 智能报价计算器
- 多纸张报价（默认 2 张，可增减），每张纸独立设置
- 纸张材质选择（9 张纸张报价表，可扩展至 30+）
- 尺寸输入（宽 × 长），支持单张 / 展开两种尺寸类型
- 附加工艺多选（双面过哑胶、烫金、UV 等）
- 批量档位快速切换（药丸按钮，一键切档重算）
- 吊绳选择 + 配送地区选择
- 三档客户等级报价卡片（毛利系数可自定义）
- 临时毛利系数快速设置（不影响默认等级，仅当前会话）
- 邮费快速修改（单独显示修改后报价卡片）
- 面积系数计算（超 10000mm² 自动按系数计价）
- 小数位数自定义（0-4 位，默认 2 位）

### 报价表组查询
- 多报价表管理（导入 Excel = 新增报价表，可切换计算）
- 全部纸张报价表浏览（下拉选择器 + 翻页两种导航）
- 搜索过滤规格代码
- 工艺价格表同步展示
- Sheet > 10 张时自动编号前缀

### 个人主页
- 公司信息设置（名称、电话、默认档位/纸张/吊绳）
- 客户等级管理（增删改、毛利系数，删除需确认）
- 一键恢复全局默认设置（清除本地配置）
- 面积系数计算说明
- 数据管理（全量导出/导入、本地备份/恢复、快照创建/删除）

### Excel 导入导出
- 纸张报价表导入导出（每个 Sheet = 一张纸，导入自动创建新报价表）
- 吊绳报价、邮费报价独立导入导出
- 9 张模板表一键下载
- 导入解析按标签匹配，兼容新旧格式
- 30+ Sheet 导入无 ID 碰撞

## 数据架构

```
小组（Group） → 总报价表（PriceList） → Sheet 纸张报价表（Paper）
```

| 层级 | 说明 | 当前值 |
|------|------|--------|
| 小组 | 独立团队/账号 | 1号小组 |
| 总报价表 | 完整报价数据集合 = 1 个 Excel 文件 | 1号报价表（可扩展多报价表） |
| Sheet 纸张 | 单张纸报价数据 = Excel 的 1 个 Sheet | 9 张（可扩展） |

每张纸含多个规格（code）× 多个档位（tier）的价格矩阵。
吊绳/邮费/客户等级为全局共享，不随报价表切换变化。

## v6.7 改动摘要（相对 v6.6）

### v6.7 直接系数档位表独立显示
- 报价表组查询页中，直接系数档位从工具栏内联文本改为「吊牌特殊工艺价格表」下方的独立框体表格（`直接系数档位表`）
- 表格按「最高倍数 / 最低倍数」两行 × 各批量档位列展示，与工艺价格表风格一致
- 无直接系数的纸张显示提示「该纸张无直接系数（最高/最低倍数为空），按标准报价计算」
- 移除工具栏中已无用的 `paperDirectCoeff` 内联元素及对应 CSS 样式
- 最新版本号统一更新至 v6.7

## v6.6 改动摘要（相对 v6.5）

### v6.6 导入导出健壮性修复
- **工艺跨报价表隔离**：导入纸张始终生成唯一 ID，不再复用默认 `paper id`，各报价表工艺完全隔离，杜绝静默覆盖
- **档位表头空列检测**：表头中间空列（误删列/合并单元格残留）导入时提示「价格可能错位」，避免价格静默错位
- **折扣系数上限校验**：折扣系数校验范围 0~10，超出回退为 1 并提示
- **全量导入数据校验**：`importFullData` 导入前执行 `validateImportedData`，防止损坏/恶意 JSON 崩溃
- **导出版本号修正**：`exportFullData` / `exportLocalBackup` 版本号更新为 6.5
- 最新版本号统一更新至 v6.6

## v6.5 改动摘要（相对 v6.4）

### v6.5 标准报价打折 / 直接系数不打折
- 标准报价模式下纸张价格 = 原价 × `paper.discount`（打折），纸张折后价合计显示折后价
- 直接系数模式下纸张始终用原价（不打折），各纸张表格单价显示原价
- 折扣只在标准报价触发，直接系数模式不触发
- 最新版本号统一更新至 v6.5

## v6.4 改动摘要（相对 v6.3）

### v6.4 去掉纸张层面折扣（原价计算）
- 所有模式下纸张均按原价计算，`paper.discount` 不再参与计算
- 折扣只通过客户等级系数（标准模式）或直接系数（直接系数模式）体现，解决"重复打折"问题
- 各纸张尺寸/面积/代码表格的单价列显示原价（如 40C棉麻布 1000张显示 ¥90）
- 查询页直接系数显示改用 `paperHasDirectCoeff` 统一校验，三行完整且数量一致时才显示
- 最新版本号统一更新至 v6.4

## v6.3 改动摘要（相对 v6.2）

### v6.3 无直接系数纸张提示
- 纸张设置卡片中，无直接系数的 Sheet（如 700布纹纸、40C棉麻布）在纸张材质下拉框下方高亮显示提示，内联显示不弹窗
- 提示覆盖所有导入场景：无直接系数、最高/最低倍数为空、档位与系数数量不一致等均显示
- `paperHasDirectCoeff` 增强校验：三行均非空且长度一致才算有效
- 最新版本号统一更新至 v6.3

## v6.2 改动摘要（相对 v6.1）

### v6.2 直接系数只读报价表表格
- 取消个人主页「直接系数设置」卡片（全局设置），直接系数只读取报价表（Excel）每个 Sheet 的「直接系数档位 / 最高倍数 / 最低倍数」三行数据
- 三行格式：最高倍数→普通客户，最低倍数→大客户，中间等级等差插值；无直接系数的 Sheet 为 null
- 有直接系数的 Sheet 不再计算折扣（使用原价），无直接系数的 Sheet 按标准报价（乘折扣系数）
- 报价表组查询页新增直接系数档位/最高/最低显示徽章
- 导出/导入/模板全面支持三行格式，无系数 Sheet 提供占位档位行方便填写
- 保留临时直接系数输入（仅影响当前显示）
- 默认报价表更新为最新表格数据

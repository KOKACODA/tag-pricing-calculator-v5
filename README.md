## 功能一览

### 智能报价计算器
- 多纸张报价（默认 2 张，可增减），每张纸独立设置
- 纸张材质选择（9 张纸张报价表，可扩展至 30+）
- 尺寸输入（宽 × 长），支持单张 / 展开两种尺寸类型
- 附加工艺多选（双面过哑胶、烫金、UV 等）
- 批量档位快速切换（药丸按钮，一键切档重算）
- 吊绳选择 + 配送地区选择
- 三档客户等级报价卡片（毛利系数可自定义）
- 临时毛利系数快速设置（不影响默认等级，仅当前会话）
- 邮费快速修改（单独显示修改后报价卡片）
- 面积系数计算（超 10000mm² 自动按系数计价）
- 小数位数自定义（0-4 位，默认 2 位）

### 报价表组查询
- 多报价表管理（导入 Excel = 新增报价表，可切换计算）
- 全部纸张报价表浏览（下拉选择器 + 翻页两种导航）
- 搜索过滤规格代码
- 工艺价格表同步展示
- Sheet > 10 张时自动编号前缀

### 个人主页
- 公司信息设置（名称、电话、默认档位/纸张/吊绳）
- 客户等级管理（增删改、毛利系数，删除需确认）
- 一键恢复全局默认设置（清除本地配置）
- 面积系数计算说明
- 数据管理（全量导出/导入、本地备份/恢复、快照创建/删除）

### Excel 导入导出
- 纸张报价表导入导出（每个 Sheet = 一张纸，导入自动创建新报价表）
- 吊绳报价、邮费报价独立导入导出
- 9 张模板表一键下载
- 导入解析按标签匹配，兼容新旧格式
- 30+ Sheet 导入无 ID 碰撞

## 数据架构

```
小组（Group） → 总报价表（PriceList） → Sheet 纸张报价表（Paper）
```

| 层级 | 说明 | 当前值 |
|------|------|--------|
| 小组 | 独立团队/账号 | 1号小组 |
| 总报价表 | 完整报价数据集合 = 1 个 Excel 文件 | 1号报价表（可扩展多报价表） |
| Sheet 纸张 | 单张纸报价数据 = Excel 的 1 个 Sheet | 9 张（可扩展） |

每张纸含多个规格（code）× 多个档位（tier）的价格矩阵。
吊绳/邮费/客户等级为全局共享，不随报价表切换变化。

## v6.1 改动摘要（相对 v6.0）

### v6.1 新报价表默认库 + Sheet 专属直接系数
- 导入 2026-08-14 新版报价表为默认数据库（10 张 Sheet，含 602米白卡）
- 直接系数改为每个 Sheet 单独配置，702铜版纸 已配置专属档位规则
- Excel 模板（基于默认数据动态生成 10 张表）/导出/导入均支持「直接系数档位规则」行

## v6.0 改动摘要（相对 v5.0）

### v6.0 直接系数档位规则可编辑
- 批量档位系数规则从硬编码常量改为可持久化变量

- 系数根据批量档位自动调整最高/最低值

## 核心原则

- 源 Excel 数据 100% 不修改
- 空值不补 0，统一用「无该批量定价」占位
- 不臆造数据，未匹配档位用 `null` 表示
- 所有 `innerHTML` 插入用户数据处使用 `escapeHtml()` 转义

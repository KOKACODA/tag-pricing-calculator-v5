## 1. main 分支是什么

`main` 是 KOKALabel 报价系统的**旧谱系主分支**，其最终版本停留在 **v7.10**（2026-09-01）。之后项目在另一台设备上重构、演化为 **v8 谱系**（推送到 `v8` 分支，终版 v8.9.0），`main` 因此转为**存档分支**，不再承担开发。

关键事实：

- **提交数**：56 次（`Initial commit` 2026-08-06 → `49db4fc` 2026-09-03）
- **版本跨度**：`v4.3` → `v7.10`，含 3 次无版本号维护提交（2026-09-02 / 2026-09-03 两段「仓库整理」「谱系归档」「精简转手」）
- **标签**：`v5.2.1-stable`、`v5.7-stable` ~ `v7.10-stable`、`v7.8-baseline`、`v7.8.1-before-quote-history`、`v7.8.1-ui-enhancements`、`v7.8.2-quote-history`、`v7.9.0-before-confirm`、`v7.9.0-inline-edit`、`v7.9.1-confirm`，以及 `archive-8.5/8.6/8.8` 三个 v8 谱系快照标签（这些 v8.x 标签是 v8 谱系搬迁时打的，非 main 谱系产物）
- **文件结构**（截至 HEAD）：`.gitignore`、`CHANGELOG.md`、`README.md`、`_headers`、`robots.txt`、`index.html`、`css/style.css`、`js/app.js`、`js/data.js`、3 个图标（无 `tests/`、无 `docs/` — 旧文档已在最后两次提交中清理或移入 v8）

### 与 v8 的关系（一句话）

> `main`（v7.10 旧谱系，独立 git 历史）与 `v8`（v8.9.0 现行谱系）**无共同提交**，属两条独立演化线，切勿跨分支 merge。全部源码与线上功能现在只维护 v8。

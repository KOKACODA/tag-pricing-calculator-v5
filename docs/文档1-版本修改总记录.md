## 1. 系统定义

| 属性 | 内容 |
|------|------|
| 系统名称 | KOKALabel 报价系统（原"海洋吊牌报价系统"） |
| 系统类型 | 纯前端单页应用（SPA），单 HTML 文件，无后端 |
| 业务场景 | 吊牌制造行业：按纸张/工艺/吊绳/邮费四要素 + 批量档位核算成本，按客户等级输出建议报价 |
| 技术栈 | HTML5 + CSS3（CSS 变量）+ 原生 JavaScript（ES6+）+ SheetJS（xlsx 0.20.1 CDN）+ localStorage |

| 产品线 | ① 报价查询系统 `KOKACODA/ocean-tag-quote-system` ② 报价计算器 `KOKACODA/tag-pricing-calculator` |

### 1.1 贯穿全部版本的三条铁律

| 铁律 | 内容 | 落实方式 |
|------|------|----------|
| 源数据不可变 | 源 Excel 100% 不被修改 | 解析层只读，全部数据在内存中处理 |
| 空值不补零 | 价格表缺失档位不得填入 0 | 解析层空值 → `null`，UI 显示「无该批量定价」占位 |
| 不臆造数据 | 未匹配档位不得向上取档 | 档位匹配采用 `hasExactTier()` 精确匹配，未命中返回 `null` |

**v2.x 计算规则（deploy-process.md 记载）**：
- 单张含出血面积 = (长+3) × (宽+3)，出血固定 3mm
- 规格匹配：取 maxArea ≥ 实际面积 的最小规格（向上匹配）
- 档位匹配：**向上取档**（目标档位不存在则取 ≥ 目标的最小档位）——此逻辑在 v3.4 被废弃
- 成本 = 纸张折后价 + 工艺费 + 吊绳费 + 邮费；邮费小面积（<2500mm²）享 0.8 折
- 三档报价 = 成本 × 1.30 / 1.15 / 1.05
